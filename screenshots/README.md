# 实机截图 / 照片（存放目录）

本目录用于存放 **无界 14xa 实机验证截图**（由仓库作者后续上传）。

## 建议命名

| 文件名 | 内容 |
|---|---|
| `01-console-battery-normal.png` | 机械革命官方控制中心：默认（Normal）模式的充电电压读数 |
| `02-console-battery-balanced.png` | 控制中心：均衡 / Balanced 模式（+100 mV per cell 降额） |
| `03-console-battery-health.png` | 控制中心：保养 / Health 模式（+200 mV per cell 降额） |
| `04-fan-quiet.png` | `Fn + X` 静音模式下的风扇转速（RPM） |
| `05-fan-balanced.png` | 均衡模式风扇转速 |
| `06-fan-performance.png` | 性能模式风扇转速 |
| `07-flash-verify-ok.png` | UEFI Shell 下 `ifux64.efi ec.bin 0 1` 刷写完成、`Verify OK` 的画面 |

## 说明

- 同一个模式下建议**同时截到电压读数**，方便与 README 里的 17600 / 17200 / 16800 mV 三档对照；
- 上传前请把序列号、机器名、账户名等隐私信息打码；
- 截图只作**观测记录**，不作为其它型号可用的依据 —— 本仓库镜像仅适用于无界 14xa（GX4HRXL / IT5571）与 EC-V14.6_A 基线。
